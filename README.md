# Laboratório de Cibersegurança: Autenticação e Força Bruta

## Sobre o projeto

Este repositório documenta meus estudos no laboratório **"Criando um Ataque de Brute Force de Senhas com Medusa e Kali Linux"**, do Bootcamp Santander de Cibersegurança, na plataforma DIO.

O foco é compreender os riscos de credenciais fracas e de tentativas automatizadas de autenticação em **ambientes de laboratório autorizados**, além de identificar medidas de proteção.

> **Importante:** Este repositório é educativo. As atividades devem ocorrer apenas em máquinas próprias ou ambientes explicitamente autorizados. A documentação abaixo deve ser preenchida com resultados realmente observados durante o laboratório.

## Objetivos

- Entender conceitos de força bruta, *password spraying* e *credential stuffing*.
- Conhecer o papel das ferramentas apresentadas no curso, incluindo Kali Linux e Medusa.
- Identificar boas práticas para proteger mecanismos de autenticação.
- Registrar observações e aprendizados do laboratório.

## Boas práticas de segurança

- Utilizar senhas fortes e exclusivas.
- Habilitar autenticação multifator (MFA).
- Limitar e monitorar tentativas de login.
- Configurar alertas para comportamentos suspeitos.
- Evitar reutilizar senhas entre sistemas.
- Realizar testes apenas com autorização explícita.
